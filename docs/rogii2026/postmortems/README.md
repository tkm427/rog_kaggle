# Postmortems: 重要な失敗の深掘り

> CLAUDE.md「postmortems を書く判断基準」に該当する失敗は必ずここに記録する。

## いつ書くか

以下に該当する失敗:
- 期待スコアと実測スコアの差が大きい（例: 期待 +0.5、実測 -0.3）
- 同じパターンの失敗が 2 回続いた
- 1 週間以上を費やしたが成果が出なかった
- LB 提出で予想外の挙動（ローカル val と LB の乖離）

## ファイル命名

`pmXXX_short_title.md`（例: `pm001_dtw_failed_on_steep_zone.md`）

## 必須項目

```markdown
# pmXXX: {タイトル}

## 何を期待していたか
（事前予測。`experiments/expXXX.md` の「事前予測」と一致するはず）

## 何が起きたか
（実測値・症状。数値根拠を引用）

## なぜ起きたか（5 Why）
1. なぜ A？ → B だから
2. なぜ B？ → C だから
3. ...

## 次回どうするか
- 短期: 次の実験で試す対策
- 長期: 同じ過ちを繰り返さないためのルール化（CLAUDE.md への追記候補も含む）

## 関連実験
- expXXX, expYYY
```
