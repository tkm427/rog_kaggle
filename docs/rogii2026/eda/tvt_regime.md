# EDA: TVT 変化率分布と稀少レジームの定義

実行日: 2026-06-16  
スクリプト: `scripts/eda_overview.py`

## TVT 絶対変化率（ft/行）の分布

MD は 1ft 刻みのため「ft/行 ≈ ft/ft = 無次元傾き」と読める。

| パーセンタイル | 値 (ft) |
|---|---|
| p50 | 0.020 |
| p75 | 0.040 |
| p90 | 0.580 |
| p95 | 0.910 |
| p99 | 1.070 |
| p99.9 | 1.570 |
| max | 151.38 |

- **19.3% の行で変化量 = 0**（TVT が完全に平坦な区間）。
- 変化量が大きい行は層境界（formation boundary）跨ぎに対応。

## 稀少レジームの定義

`competition_overview.md` で定義した `val_score_rare` / `val_score_common` に対応:

| レジーム | 閾値 | 根拠 |
|---|---|---|
| **稀少（境界跨ぎ）** | `\|d_TVT/d_MD\| > 0.91 ft` | p95 |
| **通常（連続区間）** | `\|d_TVT/d_MD\| ≤ 0.91 ft` | 下位 95% |

- 稀少レジームはウェル当たり平均 **5.1% ± 2.6%** の行に相当（ウェルごとにばらつき大）。
- 超大ジャンプ（> 5 ft）: 全 tail 行の **0.0014%**（≈ 69 行）。これは特異点的な層跨ぎ。

## 含意

- RMSE はジャンプ点で悪化しやすい（二乗誤差が支配）。
- Savitzky-Golay スムージングをジャンプ点にかけると悪化する → 後処理は「通常区間のみ」に限定すべき。
- 稀少レジームを別途モニタリングして「どのウェルで失敗しているか」を把握する。

## TVT と -Z の相関

`Corr(TVT, -Z) = 0.917`（1本目ウェルの例。**773ウェル全体での検証なし**）。  
→ `-Z`（= TVD の絶対値）は TVT の近似値として使える場合があるが、
  **exp003（2026-07-01）でworst 10ウェルのうち4件でtail内の -Z とTVTのネット変位の符号が反転**
  しており、全ウェルに一般化できる保証はない。
  LightGBMのfeature importance（gain）でも `neg_Z` 単体は5.4%に過ぎず、
  X(16.5%), Y(14.4%), delta_Z(11.7%)の方が支配的。
